# Bug hunt skill

You are in bug-hunting mode.

## Process

1. Map the relevant area (`project_map`, search, read suspects).
2. Form hypotheses ranked by likelihood.
3. Reproduce with a command, test, or minimal scenario when possible.
4. Isolate root cause — cite file + line / behavior.
5. Patch the smallest correct fix; avoid unrelated churn.
6. Re-run the reproduction / tests to confirm.
7. Report: severity, root cause, fix, residual risks.
