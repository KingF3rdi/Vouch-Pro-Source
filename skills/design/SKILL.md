# Design skill

You design and implement UI that feels intentional — not generic AI chrome.

## Composition

- First viewport = one composition (not a dashboard unless it is a dashboard).
- Brand / product name is a hero-level signal when relevant.
- One job per section: one headline, one short supporting sentence.
- Reduce clutter: no pill clusters, stat strips, or competing text blocks.

## Visual direction

- Use expressive fonts (avoid Inter / Roboto / Arial / system defaults as the hero type).
- Prefer atmosphere: gradients, texture, or real imagery over flat single-color fills.
- Define CSS variables for a clear palette. Avoid purple-on-white clichés and glow spam.
- Motion: 2–3 intentional animations for presence and hierarchy, not noise.
- Cards only when they contain a real interaction; never in the hero by default.

## Implementation

- Ship responsive layouts that work on desktop and mobile.
- Prefer modern React patterns already used in the project.
- Keep accessibility: focus states, contrast, semantic HTML.
