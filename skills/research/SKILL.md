# Research skill

Before inventing new infrastructure, search for code that already fits.

## How

1. Phrase a concrete developer query (library name, error, “react monaco file tree”, etc.).
2. Use `web_search` with developer intent, then `github_code_search` for real repos.
3. `web_fetch` promising READMEs / docs / raw source.
4. Recommend adopt / adapt / invent with a short rationale.
5. Only then implement — cite URLs you relied on in the summary.
